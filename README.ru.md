# PS5 Quiet

[English](README.md) · [Скачать](https://github.com/honkhonk-mi/ps5-quiet/releases/latest) · [Сообщить о проблеме](https://github.com/honkhonk-mi/ps5-quiet/issues)

Кнопка **«Утихомирить фаны»** для Decky Loader на PS5 Linux.

Откройте **Decky → PS5 Quiet** в меню Steam при закрытой игре и нажмите кнопку.
Она повторяет проверенный на этой консоли приём: кратко повышает минимальную
частоту GPU с 500 до 625 МГц, ждёт две секунды и возвращает прежний минимум.
Если исходный минимум другой, выбирается ближайшая разрешённая ступень выше него
в пределах текущего максимума. При зафиксированной частоте или активной нагрузке
операция не запускается.

Это обход наблюдавшегося горячего состояния GPU, а не гарантированное исправление
всех причин нагрева. После успешной операции температура и обороты снижаются
постепенно, если причиной было именно это состояние. Показания частоты берутся
из драйвера и не являются независимым измерением аппаратной частоты.

## Проверенная система

Оригинальная PS5, PS5 Bazzite Deck v2.7.3, ядро 7.3.1-viva, Decky Loader v3.3.1.
В одной проверке на рабочем столе температура снизилась с 63,5 до примерно
49–52 °C за следующие 30 секунд, а PWM вентилятора — с 43 до 24–25%.
Это результат на одной консоли, а не гарантия для всех моделей и ядер.
Значение вентилятора — процент PWM, не обороты в минуту.
Интерфейс версии 1.0.0 на русском языке.

Нужен драйвер с `/sys/class/devfreq/ps5-gpufreq` и Decky с поддержкой API 1.
Плагин предназначен для PS5 Linux; на штатной системе PS5 он не работает.

## Совместимость с охлаждением

Плагин **не записывает** `pwm`, `pwm_enable`, целевую температуру вентилятора,
профиль CoolerControl, governor, максимальную частоту GPU или параметры CPU.
Вентилятором продолжает управлять CoolerControl. Не меняйте GPU-частоту в другом
приложении во время двухсекундной операции. При обнаружении внешнего изменения
плагин сохраняет чужое значение и сообщает об этом.

Нормальный запуск плагина только читает состояние. Автоматического сброса при
старте и отдельной фоновой службы нет. В runtime-каталоге Decky хранится запись
незавершённой операции: если она была прервана, при перезапуске плагин пытается
вернуть собственный временный минимум в рамках той же загрузки Linux. Записи
от другой загрузки не применяются.

## Установка и удаление

1. На уже настроенной PS5 Linux установите [Decky Loader](https://github.com/SteamDeckHomebrew/decky-loader).
2. В [Releases](https://github.com/honkhonk-mi/ps5-quiet/releases/latest) скачайте из Assets **`ps5-quiet-v1.0.1.zip`**.
   Автоматические архивы GitHub «Source code» предназначены для разработки, не установки.
3. В настройках Decky включите режим разработчика, если он выключен.
   В разделе **Developer / Разработчик** выберите установку плагина из ZIP,
   укажите скачанный архив и подтвердите запрос Decky. Плагину нужен доступ
   root для изменения минимальной частоты GPU.
4. Закройте игру, откройте **Decky → PS5 Quiet → «Утихомирить фаны»**.
   Подождите снижения температуры и реакции вентилятора. Между сбросами есть
   пауза в десять секунд.

Можно также вставить прямую ссылку на архив релиза в поле установки Decky из URL.

Удаление: Decky → настройки плагинов → PS5 Quiet → удалить. Никаких дополнительных
настроек автозапуска удалять не требуется. Перед удалением дождитесь завершения
сброса. Runtime-запись содержит только исходную и временную частоту и ID загрузки.

## Разработка и проверка

```sh
# Node.js 24 и Python 3.10+; Linux или macOS
npm ci --ignore-scripts
npm run typecheck
npm run build
npm test
python3 scripts/package.py
```

Архив установки и контрольная сумма SHA-256 появятся в `artifacts/`.

Тесты моделируют возврат после ошибки, восстановление после перезапуска плагина,
конкурирующую запись частоты, заблокированную частоту, нагрузку, повторный запуск,
старую запись от другой загрузки и отсутствие записей в управление вентилятором.
Они не доказывают охлаждение на каждой модели/версии ядра. На конкретной консоли
нужно проверить фактический возврат минимума и температуры.

Основан на официальном [Decky plugin template](https://github.com/SteamDeckHomebrew/decky-plugin-template).
Использует API 1 и официальный `@decky/api` / `@decky/ui`.
